# Engineering Evidence Index

This index gives reviewers a direct route from the portfolio overview to concrete engineering artefacts in the showcase repositories. It focuses on evidence that can be inspected in GitHub: tests and validation, security or architecture documentation, and representative implementation material.

Repository evidence is **not** a claim that every example is deployed in production, that a control is certified, or that a configuration is suitable for an adopter without review. Each repository's own scope, limitations, and validation notes remain authoritative.

## How to use the index

For a quick technical review, start with **Tests and validation** to see what the repository checks automatically. Use **Security, architecture, and operations** to understand trust boundaries, limitations, and operational decisions. Then inspect **Representative artefacts** to see the configuration, policy, examples, or reusable material the repository is designed to demonstrate.

The [project map](project-map.md) provides the complementary view: it explains how these repositories fit together, while this page points to the evidence behind them.
